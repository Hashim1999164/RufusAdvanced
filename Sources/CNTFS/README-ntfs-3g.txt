This directory embeds libntfs-3g and mkntfs from ntfs-3g (GPLv2+, see COPYING-ntfs-3g.txt) so RufusAdvanced
can format NTFS and copy files to it without macFUSE. Changes from upstream:

- libntfs-3g/unix_io.c is not included: rufus_ntfs.c provides ntfs_device_unix_io_ops, working on an open
  descriptor and a byte range (authopen descriptors of raw disks), with sector aligned read-modify-write.
- ntfsprogs/mkntfs.c: main() renamed to mkntfs_main() so it can run in-process; mkntfs_cleanup() also
  resets g_allocation and frees g_upcaseinfo so it can run more than once per process.
- Volumes are opened in ignore-case mode (ntfs_set_ignore_case) so lookups behave like Windows. New names
  use ntfs-3g's POSIX namespace, like media created by WoeUSB / ntfs-3g mounts, which Windows Setup and the
  UEFI:NTFS driver read fine.
- ntfs-3g-include/config.h was generated by ./configure on macOS (--disable-ntfs-3g --disable-crypto).
  It also #undefs DEBUG (SwiftPM defines it for debug builds; it enables per-I/O trace logging).
